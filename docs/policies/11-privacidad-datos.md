# Aviso de privacidad para colaboradores

**Versión:** 1.0  
**Vigencia:** 2026-01-01  
**Responsable:** Recursos Humanos y Seguridad de la Información, TicoTalento S.A.

## Datos tratados

El portal usa identidad, rol, departamento, saldos, solicitudes y registros de uso para prestar el servicio interno. En este MVP todos los datos son ficticios.

## Acceso y finalidad

Una persona colaboradora solo puede consultar sus propios datos. RRHH accede a reportes agregados necesarios para la operación. Los registros del chat se usan para auditoría, mejora de documentos y atención de escalaciones.

## Seguridad y conservación

Las credenciales se almacenan fuera del repositorio. Cada consulta deja trazabilidad de agente, fuentes usadas, resultado y tiempo de respuesta. El sistema no debe registrar contraseñas, claves API ni diagnósticos médicos en el chat.

## Derechos y consultas

Las consultas sobre tratamiento de datos se dirigen a RRHH. Ninguna respuesta automática sustituye la atención de una solicitud formal de privacidad.
